## Intentional adaptations

Keep the reference's primitives, but replace its content with the real iPhone app. One semantic H1 replaces the reference's three H1 elements. No copied Detail awards, branding, footage, testimonials or AI claims. No third-party page scripts, trackers or newsletter collection. The hero uses a 20px top inset, 24px text/action gaps and a tightly joined device stage and a concise one-line desktop description so the three product previews appear in a 708px-tall viewport. The exact 130px display and 28px supporting type are retained. Tablet type interpolates between measured endpoints. The existing approved icon is preserved. The QR and CTA use the same beta email link pending a real install URL.
